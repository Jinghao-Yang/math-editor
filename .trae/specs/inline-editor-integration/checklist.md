- [ ] 检查 Editor 组件是否正确接受 documentId 作为 props
- [ ] 验证双栏布局在不同屏幕尺寸下的响应式表现
- [ ] 检查点击文档卡片是否正确打开编辑器
- [ ] 验证编辑器内容与文档匹配
- [ ] 测试返回按钮功能
- [ ] 确认新文档创建后直接进入编辑模式
- [ ] 检查所有编辑器功能是否正常（数学公式、Markdown、同步等）
- [ ] 验证视图切换功能（Kanban/Calendar）正常工作
- [ ] 测试侧边栏导航是否仍然可用
- [ ] 检查编辑器打开/关闭动画是否流畅
- [ ] 运行类型检查确保无错误
- [ ] 运行构建确保无错误
- [ ] 在浏览器中手动测试整个用户流程
